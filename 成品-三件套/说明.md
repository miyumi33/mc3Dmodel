# 三件套 · 3D 粒子效果（奥特曼 / 马 / 帆船）

用 **NebulaFX 的 GPU 实例化**渲染点云，CPU 每 tick 只花约 0.02 条命令。

---

## 一、需要装什么

| 必备 | 说明 |
|---|---|
| Minecraft 1.21.1 + Fabric Loader | 已在 `fabric-loader-0.20.1-1.21.1` 验证 |
| [Nebula 1.0.8+1.21.1](https://github.com/atemukesu/Nebula/releases/tag/v1.0.8) | 渲染引擎 |
| [ThreatenGL 2.0.4+](https://modrinth.com/mod/threatengl) | **必须**，MC 默认只给 GL 3.2，实例化要 3.3 |
| [YACL 3.8.2+](https://modrinth.com/mod/yacl) | Nebula 的配置界面依赖 |
| Fabric API | 基础 |

---

## 二、装文件

```
运行/动画/*.nbl      → .minecraft/versions/<版本>/nebula/animations/
运行/资源包/*.zip    → .minecraft/versions/<版本>/resourcepacks/   （游戏内启用）
运行/数据包/*.zip    → <存档>/datapacks/
```

**改完必须重启游戏**：Nebula 只在启动时扫描 `nebula/animations/`。

---

## 三、用

```mcfunction
/reload                      ← 第一次进世界必敲
/function fx:tiga/start      ← 奥特曼（41.4 万粒子）
/function fx:horse/nbl       ← 马（150 万粒子）
/function fx:ship/start      ← 帆船（100 万粒子）
/function fx:stop            ← 全部停止
```

三个效果**在玩家位置生成**，正面朝向玩家，站在空地上直接敲即可。

> Nebula 一次只播一个动画（`nebula clear` 是全局的），所以是轮流看，不能同屏。

## 五、重新生成

`源码/` 里是完整的生成链，只需要 Python 3.10+ 和 `numpy / Pillow / zstandard`。

```bash
cd 源码

# 奥特曼（体素化 0.20，近白配色）
python tools/ginga_accent.py --out ../运行/动画/ginga.nbl     --yaw 180 --lattice 0.20 --size 20 --silver "240,244,250"

# 马
python tools/obj_to_nbl.py 模型/horse/horse_uv.obj --out ../运行/动画/horse.nbl     --points 1500000 --height 120 --size 16 --frames 6 --fps 1     --offset "0,60,-45" --tex-dir 模型/horse/textures

# 帆船
python tools/obj_to_nbl.py 模型/ship/ship_uv.obj --out ../运行/动画/ship.nbl     --points 1000000 --height 120 --size 18 --frames 10 --fps 1     --offset "0,55,-64" --tex-dir 模型/ship/textures
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--points` | 点数（决定密度） |
| `--size` | 粒子大小，单位 1/100 格（16 = 0.16 格） |
| `--lattice` | 体素化格距（格），0=随机撒点；越大越稀越整齐 |
| `--height` | 按身高缩放到多少格 |
| `--scale-axis` | `y`=按身高（武器很长时用），`auto`=按最长边 |
| `--offset` | 整体平移 `x,y,z`（Minecraft 北 = -Z） |
| `--yaw` | 绕 Y 旋转，180 = 正面朝玩家 |
| `--frames` / `--fps` | 帧数 / 帧率（静止画面靠重播实现"循环"） |

## 六、`.nbl` 格式（自己写的导出器，非官方插件）

```
"NEBULAFX" | u16 版本=1 | u16 fps | u32 帧数 | u16 贴图数 | u16 3
| 28B 保留(bbox) | 贴图表 | 帧索引(12B/帧) | 关键帧表
帧块 = zstd( u8 类型 + u32 N + [x[N] y[N] z[N] | r/g/b/a 各[N] | size u16[N] | tex | seq | pid i32[N]] )
```

- 颜色是**平面排列**（先所有 R，再所有 G…），不是交错
- `size` 单位是 1/100 格
- 第 0 帧是 I 帧（全量），之后是 P 帧（全零差分，静止画面）

## 八、排错

| 现象 | 原因 | 解决 |
|---|---|---|
| 动画不出现 | 没重启游戏 | Nebula 只在启动时扫描目录 |
| `未知的函数` | 数据包没启用 | `/datapack list` 查看，或 `/datapack enable "file/xxx.zip"` |
| 什么都没画 | 未装 ThreatenGL | 日志会写 `OpenGL < 3.3, skipping` |
| 播几秒就消失 | 循环没启动 | 用 `fx:<name>/start`，不要直接 `nebula play` |
| 看得到背面 | 动画不跟随朝向 | 用 `/start`（已做 `--yaw 180`）；或走到另一侧 |
| 角色多出一个"不动的" | 旧位置残留实例 | 重新 `/function fx:xxx/start`（会先 `nebula clear`） |
